Rotoscope Procedure

First Step:

  1. Launch Adobe After Effects and create a new project.
  2. Import the video file you want to edit.
  3. Place the video onto a new composition.
  4. Make five copies of the video layer by pressing Ctrl + D.
  5. Rename each duplicated layer according to the object it will represent (e.g., Hair, Skin, Shirt, Pants, and Shoes).

Second Step:

  1. Open one duplicated layer by double-clicking it.
  2. Enable the Roto Brush Tool using Alt + W.
  3. Highlight only the selected body part with green strokes.
  4. Remove unwanted selections by drawing red strokes over the background or other objects.
  5. Preview the clip so the Roto Brush can analyze and track the selection throughout the video.
  6. Once the selection is accurate, click Freeze in the Effect Controls panel to lock the mask.
  7. Repeat the same process for each remaining duplicated layer.

Third Step:

  1. Select one of the completed layers.
  2. Go to Effect → Generate → Fill.
  3. Choose the desired color for that body part.
  4. Repeat the process until all isolated layers have their assigned colors.

Fourth Step:

  1. Create a new solid by selecting Layer → New → Solid.
  2. Set the solid's color to green (or another preferred background color).
  3. Move the solid layer beneath all other layers in the composition so it appears as the background.

Fifth Step:

  1. Open the Render Queue by pressing Ctrl + M.
  2. Select your preferred output format and destination folder.
  3. Review the render settings.
  4. Click Render to export the completed video.
