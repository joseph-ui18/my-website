Domain Controller

What is a Domain Controller?

A Domain Controller (DC) is a server that manages network security, user authentication, and access to resources within a Windows domain. It uses Active Directory to store user accounts, passwords, and policies.

Domain Users

Domain users are accounts created in Active Directory that allow users to log in and access network resources.

DHCP

Dynamic Host Configuration Protocol (DHCP) automatically assigns IP addresses to devices in the network.

File Sharing

File sharing allows users to access shared folders and files over the network.

RAID

RAID (Redundant Array of Independent Disks) improves storage performance and provides data redundancy.

Remote Desktop

Remote Desktop allows users to connect and control another computer remotely.

Web Server

A web server hosts websites and applications using services like IIS.

Group Policy

Group Policy allows administrators to control settings and security policies across all computers in the domain.

Windows Deployment

Windows Deployment Services (WDS) helps install Windows OS over the network.
