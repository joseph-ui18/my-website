Description

This Solar System project introduces the planets, moons, and basic space science concepts. It explains how the system is organized, how the planets move, and what makes Earth unique among the planets.

Method

Step 1: Download Textures

Go to solarsystemscope.com/textures and download all required texture files. Save them in one folder (e.g. C:/Users/Joseph/Downloads/textures/).

Step 2: Set Up Blender

1. Open Blender
2. Go to the Scripting tab
3. Click New to create a script
4. Paste the Python script into the editor
5. Update texture path:
TEX = "C:/Users/Joseph/Downloads/textures/"

Step 3: Run the Script

1. Click Run Script or press Alt + P
2. Wait for “Done!” message
3. The scene will generate planets, Sun, Moon, rings, and stars

Step 4: Check the Scene

1. Press Numpad 0 for camera view
2. Press Space to preview animation
3. Verify all planets are visible and moving

Step 5: Render the Animation

1. Go to Render menu
2. Click Render Animation or Ctrl + F12
3. Blender renders 250 PNG frames
4. Wait for rendering to finish

Step 6: Find Rendered Frames

Default location: C:\tmp\
Files: 0001.png to 0250.png

If missing:
1. Go to Properties → Output tab
2. Check Output Path

Step 7: Convert to Video (FFmpeg)

Run this command in Command Prompt: 

ffmpeg -framerate 24 -i "C:/tmp/%04d.png" -c:v libx264 -pix_fmt yuv420p "C:/Users/Joseph/OneDrive/Desktop/solar_system.mp4"

Sun

The Sun is the star at the centre of our solar system. It is an almost perfect sphere of super-hot gases whose gravity holds the solar system together. The energy produced by the Sun is essential for life on Earth and is a driving force behind the Earth's weather.

Mercury is the closest planet to the Sun and due to its proximity it is not easily seen except during twilight. For every two orbits of the Sun, Mercury completes three rotations about its axis and up until 1965 it was thought that the same side of Mercury constantly faced the Sun.

Script

Blender Python Script used for the Solar System project:

import bpy
import math

# Clear scene
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.delete(use_global=False)

for mesh in bpy.data.meshes:
    bpy.data.meshes.remove(mesh)
for mat in bpy.data.materials:
    bpy.data.materials.remove(mat)
for img in bpy.data.images:
    bpy.data.images.remove(img)
for action in bpy.data.actions:
    bpy.data.actions.remove(action)

TEX = "C:/Users/Joseph/Downloads/textures/"

# Helper: textured material
def load_tex_mat(name, filepath, emission=0.0, roughness=0.85):
    mat = bpy.data.materials.new(name=name)
    mat.use_nodes = True
    nodes = mat.node_tree.nodes
    links = mat.node_tree.links
    nodes.clear()

    out  = nodes.new("ShaderNodeOutputMaterial")
    bsdf = nodes.new("ShaderNodeBsdfPrincipled")
    tex  = nodes.new("ShaderNodeTexImage")
    uv   = nodes.new("ShaderNodeTexCoord")

    tex.image = bpy.data.images.load(filepath)
    bsdf.inputs["Roughness"].default_value = roughness

    links.new(uv.outputs["UV"], tex.inputs["Vector"])
    links.new(tex.outputs["Color"], bsdf.inputs["Base Color"])
    links.new(bsdf.outputs["BSDF"], out.inputs["Surface"])

    return mat

# Planet
def make_planet(name, radius, distance, angle=0):
    x = math.cos(angle) * distance
    y = math.sin(angle) * distance

    bpy.ops.mesh.primitive_uv_sphere_add(radius=radius, location=(x, y, 0))
    obj = bpy.context.active_object
    obj.name = name
    bpy.ops.object.shade_smooth()
    return obj

# Orbit animation
def orbit(obj, radius, speed):
    for f in range(1, 251):
        angle = math.radians(speed * f)
        obj.location.x = math.cos(angle) * radius
        obj.location.y = math.sin(angle) * radius
        obj.keyframe_insert("location", frame=f)

# Sun
sun = make_planet("Sun", 2.0, 0)
sun.data.materials.append(load_tex_mat("SunMat", TEX+"sun.jpg", emission=4.0))

# Earth
earth = make_planet("Earth", 0.5, 9.0, 1.6)
earth.data.materials.append(load_tex_mat("EarthMat", TEX+"earth_daymap.jpg"))

# Moon
bpy.ops.mesh.primitive_uv_sphere_add(radius=0.13, location=(10, 0, 0))
moon = bpy.context.active_object

# Lights
bpy.ops.object.light_add(type='POINT', location=(0,0,0))

# Animation
orbit(earth, 9.0, 0.3)

print("Done! Press Space to play animation, F12 to render.")
