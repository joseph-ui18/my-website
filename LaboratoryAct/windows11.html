Windows 11

About Windows 11

Windows 11 is the latest major release of Microsoft's desktop operating system, featuring a redesigned interface, centered Start menu, updated window management, and enhanced security and hardware requirements.

It also introduces improvements for gaming, virtual desktops, and integration with Microsoft services.

During the Windows 11 installation, I configured the virtual machine to meet the system requirements and mounted the Windows 11 ISO file. I followed the installation steps, including selecting the installation settings and allowing the system to install the operating system. After the setup was completed, Windows 11 was successfully installed and ready to use.

Lab Notes & Observations

The installation of Windows 11 began by booting the computer from a USB installer and loading the setup program. After choosing language and system preferences, the installation process continued by accepting the license agreement and selecting the custom installation option. A partition was chosen for installing the system, and Windows copied the necessary files while restarting during the process. After installation, the user configured region, keyboard layout, privacy settings, and account login. Additional features such as PIN setup and Windows Hello were configured before completing the final setup and accessing the Windows 11 desktop.
