What is Active Directory?

Active Directory (AD) is a directory service developed by Microsoft for Windows domain networks. It allows administrators to manage users, computers, and network resources in a centralized system.

Active Directory stores information about network objects such as user accounts, devices, groups, and security policies. It provides authentication and authorization services, allowing users to securely access resources within the network.

Using Active Directory, organizations can organize network resources into domains, trees, and forests, making it easier to manage large networks efficiently.

Lab Notes & Observations

In this laboratory activity, we configured Active Directory by installing the Active Directory Domain Services role and promoting the Windows Server into a domain controller. This allowed centralized management of users and computers within the network.

We also created Organizational Units (OUs) and added user accounts to simulate a real-world domain environment. Active Directory simplifies network administration by allowing administrators to control permissions, policies, and authentication from a single system.
