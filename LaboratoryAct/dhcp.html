DHCP Overview

What is DHCP?

The Dynamic Host Configuration Protocol (DHCP) automatically assigns IP addresses and other network configuration details (such as gateway and DNS servers) to client devices on a network.

In a Windows Server environment, the DHCP role simplifies IP management and reduces configuration errors, especially in networks with many workstations.
