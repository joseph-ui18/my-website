Windows 10

About Windows 10

Windows 10 introduced a unified platform across PCs, tablets, and other devices, bringing back the Start menu while adding live tiles, virtual desktops, and improved security features such as Windows Defender and BitLocker enhancements.

It follows a "Windows as a service" model, receiving regular feature and security updates instead of separate major releases.

For Windows 10, I created a virtual machine with higher system requirements and mounted the Windows 10 ISO file. I followed the installation wizard, selected the appropriate settings, and allowed the system to install the operating system. After the installation completed, Windows 10 started successfully.

System Requirements

Typical minimum requirements for Windows 10 include a 1 GHz processor, 1–2 GB of RAM, and at least 16–20 GB of available disk space, plus DirectX 9 graphics with WDDM 1.0 driver. In your VM, you can allocate more resources for a smoother experience.

Laboratory Activity Notes

The installation of Windows 10 started by booting the computer from a DVD or USB installer and launching the setup program. After selecting language, time, and keyboard preferences, the installation proceeded by accepting the license agreement and selecting the custom installation option. A partition was chosen for the installation, and Windows copied files and installed system features. After several restarts, the user configured region settings, privacy options, and account login. Additional setup steps such as creating a PIN and configuring personalization settings were completed before accessing the Windows 10 desktop.
