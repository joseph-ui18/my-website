Windows 8

About Windows 8

Windows 8 introduced a new Start screen, live tiles, and a touch‑oriented user interface designed for tablets and hybrid devices, while still supporting desktop applications.

It changed how users navigate and manage applications, which makes it interesting to compare with Windows 7 and Windows 10.

During the Windows 8 installation, I configured the virtual machine and mounted the ISO file. The installation process included selecting the installation settings and allowing the system to copy and install the necessary files. After the restart, Windows 8 was successfully installed.

Lab Notes & Observations

The installation of Windows 8 began by booting the computer from the installation media and loading the setup program. After selecting language and system preferences, the installation continued by accepting the license agreement and choosing a custom installation. The partition for installation was selected, and Windows copied files and installed system features while restarting during the process. Afterward, the user configured personalization settings, privacy options, and account login using either a Microsoft account or a local account. Final system configurations were completed before the operating system was ready to use.
