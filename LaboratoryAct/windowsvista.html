Laboratory Activity: Windows Vista

ITOS220-T

Windows Vista

About Windows Vista

Windows Vista introduced a new visual style (Aero), an overhauled networking stack, User Account Control (UAC), and many security enhancements.

It had higher hardware requirements than its predecessors and received mixed reception, making it a useful case to examine OS design trade‑offs.

When installing Windows Vista, I configured the virtual machine with higher memory and storage requirements. I mounted the ISO file and followed the graphical installation wizard. After completing the installation steps and restarting the system, Windows Vista was successfully installed.

Lab Notes & Observations

The installation of Windows Vista started by booting the computer from the Windows Vista DVD and loading the setup files. After selecting the language, time, and keyboard preferences, the installation process began by accepting the license agreement and choosing the custom installation option. A partition was selected for the installation, and the system copied files and installed features while restarting several times. Afterward, user information such as username, password, computer name, and desktop background were configured. The setup was completed by adjusting the time zone, Windows Update settings, and network configuration.
