What is an operating system?

An operating system (OS) is system software that manages computer hardware and software resources while providing services for computer programs. It acts as an intermediary between users and the computer hardware, ensuring efficient execution of applications and system processes.

An operating system performs several critical functions, including managing hardware resources like CPU, memory, and storage, running applications, handling input and output, providing security, and enabling communication between software and hardware. It ensures system stability and usability through a user-friendly interface and background operations.

Virtual Machines

A virtual machine (VM) is a software-based simulation of a physical computer that runs an operating system and applications independently from the host machine. VMs are created using virtualization technology, allowing multiple operating systems to run on a single physical computer.

In this course, you will use virtual machines to safely install, configure, and experiment with different versions of Microsoft Windows without risking your host operating system.

VirtualBox by Oracle

VirtualBox is free and open-source virtualization software that allows you to run virtual machines on your computer. It supports multiple operating systems simultaneously, enabling you to test, develop, or run applications in isolated environments without affecting the host system.

Your laboratory activities will typically start with creating a new virtual machine, attaching installation media, and then performing OS installation and configuration steps.

Final Activity

The final activity integrates concepts from all previous laboratory exercises. You will design and configure a small network using virtual machines, apply security best practices, and document your setup and troubleshooting steps.
